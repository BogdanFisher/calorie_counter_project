# Calorie Counter Project

Консольный калькулятор калорий на Python. Считает общую калорийность блюда по количеству белков, жиров и углеводов.

## Возможности

- Расчёт по формуле: 4 ккал/г белка, 9 ккал/г жира, 4 ккал/г углеводов.
- Валидация ввода: защита от нечисловых значений и отрицательных чисел (через `try/except` и цикл).
- Форматированный вывод: результат с точностью до одного знака после запятой (f‑строка `{value:.1f}`).
- Покрытие тестами: базовые кейсы (обычные числа, нули, дробные значения) на `pytest`.
- Чистый репозиторий: настроен `.gitignore` для исключения мусора (`__pycache__`, `venv` и т.п.).

## Формула

Общая калорийность рассчитывается по формуле:

`калории = 4 × белки + 9 × жиры + 4 × углеводы`
